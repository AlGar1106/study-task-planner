# Лабораторная работа 6 — отчёт

Проект: «Планировщик учебных задач». Автор: Алина Галишина. Дата: 7 ноября 2026 года.

Репозиторий: https://github.com/AlGar1106/study-task-planner

## Реализованный объём

Работающая первая версия на React + Vite: создание, просмотр, редактирование и удаление задач с подтверждением; три статуса и возврат в работу; поиск, совместные фильтры дисциплины и статуса; сортировка по сроку; выделение просроченных незавершённых задач. Все данные сохраняются в localStorage. Список первого запуска пустой.

Форма проверяет обязательные поля, пробельные названия, календарную дату и длину текста. Показаны успех, ошибки ввода, отсутствие задач и результатов поиска. При отказе записи форма не очищается, список не получает неподтверждённые изменения. Повреждённое хранилище не перезаписывается без подтверждения. Поддерживаются клавиатура, Escape в диалоге, возвращение фокуса и адаптивная раскладка из лабораторной №5.

Связь с PRD: FR-02–06. FR-01 (авторизация), серверное хранение и REST API не входят в эту первую итерацию, как разрешает задание лабораторной №6. Полное ТЗ не считается реализованным целиком. Отдельная страница деталей заменена карточкой с полным описанием и формой редактирования на одном экране.

## Последовательные этапы с ИИ

1. Основа React + Vite, команды запуска и сборки. Сборка прошла. При запуске обнаружена ошибка окружения `uv_interface_addresses` для внешнего сетевого адреса; агент заменил его локальным `127.0.0.1`, после чего Vite запускается.
2. Функции проверки задач, localStorage, фильтры, сортировка, просрочка. Пройдены 8 модульных тестов до подключения интерфейса.
3. Главный экран, форма, статусы и удаление. Production сборка и сценарий в Chromium прошли. В браузерном тесте исправлены неоднозначные селекторы одинаковых подписей поиска и формы; поля ограничены областью формы.
4. Проверка хранения, ошибок, клавиатуры и адаптивности; оформление исходников, README и отчёта. Каждый этап сохранён отдельным логическим коммитом.

Приняты предложения ChatGPT/Codex: ограничить MVP основным сценарием, использовать React + Vite и localStorage, повторно использовать CSS, добавить подтверждение удаления, защиту от ложного успеха и тесты. Redux, Router, Axios и новые UI библиотеки отложены: для одного локального экрана они не нужны. ИИ не проводил опрос пользователей; студенту остаётся самостоятельно повторить демонстрационный сценарий перед сдачей.

## Фактическая проверка

- `npm test`: 8 тестов пройдены. Проверены обязательные поля, даты и високосный год, вчера/сегодня/выполненная задача, совместные условия поиска, оба направления сортировки, повторное чтение данных, повреждённые записи и отказ доступа/записи.
- `npm run build`: production сборка успешна.
- Chromium, автоматизированный сценарий: пустой старт → ошибка пустой формы → создание → перезагрузка → редактирование названия и описания → завершение → перезагрузка → возврат в работу → фильтры и отсутствие совпадений → сортировка → отмена удаления и Escape → подтверждение удаления → перезагрузка. Текст с HTML тегами отображается как текст, код не исполняется.
- В Chromium проверены ширины 360, 768 и 1440 px: горизонтального переполнения нет. Снимки экрана просмотрены. Вход с клавиатуры начинает со ссылки перехода к содержимому.
- Искусственный отказ записи: форма сохраняет ввод, ложного успеха нет. Повреждённый JSON остаётся неизменным после чтения и отмены сброса; новый список создаётся только после подтверждения.
- В проверенном сценарии нет ошибок JavaScript и сообщений console.error. Проверка не заменяет испытания в других браузерах и на физических телефонах.

## Запуск и ручная демонстрация

Node.js 22.12+; проверено на 24.22.1. В терминале корня проекта: `npm ci`, затем `npm run dev`. Открыть адрес Vite (обычно http://127.0.0.1:5173). Старый tempPage/index.html остаётся статическим материалом лабораторных №4–5.

1. Создать «Лабораторная 6», дисциплина «Веб разработка», произвольная корректная дата.
2. Изменить описание, найти задачу по части названия, выбрать её дисциплину и статус.
3. Сбросить фильтры; завершить задачу, обновить страницу и проверить сохранение. Вернуть в работу.
4. Нажать «Удалить» и «Отмена»: задача остаётся. Подтвердить удаление: задача исчезает и после обновления страницы.
5. Повторить на узком экране; проверить пустую форму и ошибку поиска.

Для повторения браузерной автоматизации: `npx playwright install chromium`, затем `npm run test:browser`. Она запускает локальный сервер готовой production сборки и создаёт временные снимки в test-results (не входит в Git).

## Ограничения

Один пользователь и браузер; нет backend, авторизации, API, PostgreSQL, синхронизации устройств/вкладок, резервной копии и уведомлений. Очистка данных браузера удаляет задачи. Если localStorage недоступен, операции сохранения блокируются или показывают ошибку. Данные для основного сценария проверены; критических ошибок в проверенном сценарии не обнаружено. Облачное размещение и работа на реальных мобильных устройствах не проверялись.
