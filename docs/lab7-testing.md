## Запуск

Нужен Node.js 22.12+ и npm. Открыть корневую папку проекта в терминале или VS Code:

```sh
npm ci
npx playwright install chromium
npm run test:requirements
```

На Linux при отсутствии системных библиотек браузера вместо второй команды можно использовать `npx playwright install --with-deps chromium`.

Команда `test:requirements` сама собирает приложение, запускает временный локальный сервер на свободном порту, выполняет тесты и закрывает сервер и браузеры. `npm run dev` отдельно запускать не нужно. Для имеющихся восьми модульных тестов из лабораторной №6: `npm test`.

Ожидаемая итоговая сводка:

```text
tests 6
suites 3
pass 6
fail 0
skipped 0
```

## Запуск и исправление ошибок

Первый прогон: T01 пройден, следующие пять тестов не смогли выполниться из-за завершения Chromium при повторном открытии контекста. Проблема связана с используемым однопроцессным браузером тестового окружения. Исправлен жизненный цикл: каждый тест теперь запускает и закрывает отдельный браузер, сохраняя изоляцию данных.

Повторный прогон на Node.js 24.22.1 и headless Chromium: **6 из 6 тестов пройдены**, три группы требований, ошибок JavaScript/console.error в сценариях нет. Production сборка успешна. Ошибок приложения в выбранных сценариях не обнаружено; бизнес-логика не изменялась.

В среде выполнения использован отдельный исполняемый файл Chromium, путь и параметры переданы через переменные PLANNER_BROWSER_EXECUTABLE и PLANNER_BROWSER_ARGS. На обычном компьютере эти переменные не требуются: Playwright использует браузер из команды установки.
