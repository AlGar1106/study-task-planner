# Планировщик учебных задач

Первая работающая версия MVP из лабораторной №6. Студент добавляет задания, указывает дисциплину и срок, меняет статус, ищет и фильтрует свои задачи.

## Запуск через VS Code

Нужен Node.js 22.12+ (проверено на Node.js 24.22.1) и npm.

1. Скачайте проект: Code → Download ZIP на GitHub, затем распакуйте архив. Или выполните `git clone https://github.com/AlGar1106/study-task-planner.git`.
2. В VS Code выберите «Файл → Открыть папку» и откройте корневую папку проекта, где находится package.json.
3. Откройте «Терминал → Создать терминал» и выполните:

```sh
npm ci
npm run dev
```

4. Перейдите по адресу, который напечатает Vite, обычно http://127.0.0.1:5173. Оставьте терминал работающим. Для остановки нажмите Ctrl+C.

Корневой index.html запускается через Vite; двойной щелчок по нему не запускает React приложение. `tempPage/index.html` — сохранённая статическая версия лабораторных №4–5; её по-прежнему можно открыть двойным щелчком.

## Что работает

- Создание задачи: название, дисциплина и корректная дата обязательны; описание необязательно.
- Просмотр, редактирование и удаление с подтверждением. Отмена и Escape не удаляют задачу.
- Статусы «Запланирована», «В работе», «Выполнена», включая возврат выполненной задачи в работу.
- Поиск по названию без учёта регистра, совместные фильтры дисциплины и статуса, сброс условий.
- Сортировка по сроку в обе стороны. Вчерашняя незавершённая задача просрочена; сегодняшняя и выполненная — нет.
- Сохранение всех задач после обновления страницы в localStorage этого браузера.
- Пустой список, отсутствие совпадений, ошибки полей и хранения. При отказе сохранения данные формы остаются, ложный успех не показывается.
- Адаптивная раскладка, подписи полей, клавиатурный фокус и модальное подтверждение удаления.

Первый запуск показывает пустой список. Демонстрационные задачи автоматически не добавляются.

## Проверки и сборка

```sh
npm test
npm run build
npm run preview
```

`npm test` запускает 8 тестов валидации, дат, фильтров, сортировки и хранения. Сборка попадает в dist (папка исключена из Git); preview позволяет проверить её локально.

Браузерные проверки (по желанию): `npx playwright install chromium`, затем `npm run test:browser`.

Полный протокол приёмки, сценарий ручной демонстрации и ограничения: [docs/lab6-report.md](docs/lab6-report.md). Объём, решения и последовательные задания ИИ: [docs/lab6-plan.md](docs/lab6-plan.md).

## Лабораторная работа 7 — тесты трёх требований

Добавлены **6 отдельных браузерных тестов** в [tests/requirements.test.mjs](tests/requirements.test.mjs):

- FR-05: поиск и совместные фильтры (T01–T02).
- FR-02: ошибки обязательных полей, пробельное название и успешное сохранение (T03–T05).
- FR-04: изменение статуса, сохранение после обновления и возврат в работу (T06).

Для каждого теста ожидаемый результат и результат запуска указаны в [docs/lab7-testing.md](docs/lab7-testing.md).

Запуск из корневой папки проекта:

```sh
npm ci
npx playwright install chromium
npm run test:requirements
```

На Linux без библиотек браузера используйте `npx playwright install --with-deps chromium`. Команда тестирования сама собирает приложение и запускает временный сервер на свободном порту. Ожидается: **6 tests, 6 pass, 0 fail**. Каждая проверка использует отдельный браузер и пустое хранилище; обычные личные данные пользователя не затрагиваются. Проверены headless Chromium и Node.js 24.22.1.

## Структура

- `index.html`, `src/main.jsx` — точка входа React.
- `src/app/App.jsx` — список задач, фильтры, состояние и обработчики действий.
- `src/components/TaskForm.jsx` — создание, редактирование и ошибки ввода.
- `src/components/DeleteDialog.jsx` — окно подтверждения удаления с управлением фокусом.
- `src/features/tasks/tasks.js` — проверка данных, фильтрация, сортировка, localStorage.
- `src/features/tasks/tasks.test.js` — автоматические проверки логики.
- `src/styles/app.css` — дополнительные состояния работающей версии; основное оформление импортируется из `tempPage/styles.css`.
- `tempPage/` — неизменённые материалы лабораторных №4–5.
- `docs/` — backlog, объём MVP, отчёт и задания для ИИ.

## Ограничения первой версии

Один пользователь, один браузер. Авторизация, сервер, REST API, PostgreSQL, синхронизация между устройствами и вкладками, резервное копирование и уведомления ещё не реализованы. Очистка данных браузера удаляет список. Если localStorage запрещён, работа с сохранением недоступна; приложение показывает ошибку. Повреждённые записи не заменяются без явного подтверждения пользователя. Не используйте этот учебный MVP для чувствительной информации.

Технологии: React, React DOM, Vite, CSS. Дополнительные библиотеки состояния, маршрутизации и API в этой итерации не нужны. Полный стек из ТЗ остаётся планом дальнейшего развития.
