# Планировщик учебных задач

Учебный проект: студент добавляет задания, указывает дисциплину и срок, меняет статус, ищет и фильтрует свои задачи.

## Текущий этап
Лабораторная работа №4: начальная структура репозитория и семантическая HTML страница. React приложение и backend пока не реализованы. Содержимое src — папки для следующих этапов, зависимости ещё не установлены.

## Просмотр страницы
Откройте `tempPage/index.html` в любом современном браузере. Установка Node.js для этой страницы не нужна. CSS задаёт только ширины, расположение, отступы и типографику. Данные демонстрационные; поиск, фильтры и изменение задач ещё не подключены, кнопки действий отключены.

## Планируемый стек
Frontend: React, Vite, React Router, Redux Toolkit, Axios, Tailwind CSS. Backend по ТЗ: Django REST Framework и PostgreSQL. Подключение API и установка зависимостей запланированы в backlog.

## Структура
- `tempPage/` — временная главная страница на HTML и CSS.
- `src/app/` — маршруты и состояние приложения.
- `src/pages/` — страницы входа, регистрации и задач.
- `src/components/` — общие элементы интерфейса.
- `src/features/auth/`, `src/features/tasks/` — модули авторизации и задач.
- `src/services/` — обращения к API.
- `src/styles/`, `public/` — стили и публичные ресурсы.
- `docs/` — backlog в Markdown и CSV для YouGile.

## Основные требования
Вход и регистрация, создание, просмотр, изменение и удаление собственных задач с подтверждением, три статуса, совместные фильтры, поиск и сортировка по сроку, отметка просрочки.
